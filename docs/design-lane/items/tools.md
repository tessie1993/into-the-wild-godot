# Tools, Vessels & Signals — Into the Wild

> Status: design draft. Costs verified vs `economy-engine.md` §4.1 budgets (C 2–3 / U 6 / R 18 / L 54 CE). Effects need playtest.
> **Independent tiering:** each chain tier is crafted from scratch — no item exchange. Items are permanent.
> Progression: C/U = outer ring turns 1–4 · R = inner ring + bench turns 5–10 · L = inner/Ascended turns 10+ (needs Crafting Bench).

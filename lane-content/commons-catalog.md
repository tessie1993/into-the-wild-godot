# Commons Catalog — 100 Common Resources

> Expansion of `resources.md` Common staples. **Physical build: Commons remain 6 element token colors** — these names are flavor subtypes printed on terrain/reference cards (any Wood common = 1 green token). **Digital build** may track each name individually for recipes/flavor. All = 1 CE, unlimited carry.
